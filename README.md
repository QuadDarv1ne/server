**Sync-in — это платформа для самостоятельного развертывания (self-hosted), предназначенная для хранения файлов, синхронизации и командной работы.**

Разверните собственное рабочее пространство для файлов, документов, общих ресурсов и совместной работы, не теряя контроля над своей инфраструктурой и данными.

Sync-in разработан так, чтобы оставаться быстрым, легковесным и ориентированным на ваши данные: файлы остаются читаемыми в вашей файловой системе, а функции совместной работы добавляются только там, где они действительно необходимы.

## Функции

- 🖥️ Современный веб-интерфейс с поддержкой перетаскивания (drag-and-drop), умным буфером обмена, режимом галереи, сортировкой, фильтрацией и расширенным предпросмотром файлов
- 🆔 Аутентификация с помощью локальных учетных записей, OIDC, LDAP, MFA, кодов восстановления и паролей для приложений
- 🔑 Пространства, общие ресурсы, гостевой доступ, персональные группы, роли и детализированные разрешения для контролируемой совместной работы
- 🔐 Защищенные публичные ссылки с ограничениями доступа, сроками действия, паролями и полным контролем над общим контентом
- 🤝 Онлайн-редактирование документов с помощью Collabora Online, OnlyOffice и Euro-Office
- 💬 Отслеживание активности, комментарии, уведомления, блокировка файлов и история последних обновлений в едином рабочем процессе
- 🔎 Полнотекстовый поиск с глубоким индексированием содержимого документов в распространенных офисных и текстовых форматах
- 📂 Квоты на хранилище, хранение удаленных файлов (корзина), инструменты защиты файлов и привязка папок без дублирования данных
- 🌍 Изначально ориентирован на самостоятельное развертывание (self-hosted), подходит для размещения на собственных серверах (on-premise) или в частном облаке
- 🔗 Поддержка WebDAV для файловых менеджеров, сетевых дисков, мобильных приложений и сторонних клиентов
- 🖥️ Десктопные и CLI-клиенты для Windows, macOS и Linux с поддержкой синхронизации с несколькими серверами
